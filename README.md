# Task 6: K-Nearest Neighbors (KNN) Classification

## Objective
To understand and implement the K-Nearest Neighbors algorithm for classification problems using Scikit-learn.

## Dataset
Used the [Iris Dataset](https://www.kaggle.com/datasets/uciml/iris).

## Tools
- Python
- Scikit-learn
- Pandas
- Matplotlib
- Seaborn

## Tasks Performed
1. Loaded and visualized the Iris dataset
2. Normalized the feature values
3. Trained KNN classifier with various values of K
4. Evaluated models using accuracy and confusion matrix
5. Visualized decision boundaries

## Results
- Best performance achieved at K = 5
- Accuracy: ~97%
- Confusion matrix shows high classification accuracy for all classes

## How to Run
```bash
pip install -r requirements.txt
python task6_knn_classifier.py
```
